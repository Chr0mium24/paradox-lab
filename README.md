# 反直觉实验室

50 个违反直觉的结论，每个都配一个可以动手调参数的模拟：布雷斯悖论、斯坦因悖论、维度灾难、筛查悖论、遍历性、网球拍定理、沙堆雪崩……

首页是一张"星图"：节点是结论，颜色是它背后的结构，连线是两个结论之间的具体关系（每条线都写了原因）。可以在"按结构"和"按现实领域"两种分组之间切换，也可以沿 9 条导览路线读。

## 运行

纯静态页面，没有构建步骤，也没有依赖：

```bash
python3 -m http.server 8781
```

然后打开 <http://localhost:8781>。直接双击 `index.html` 也能用。

## 结构

```
index.html          入口；脚本按顺序加载，带 ?v=N 防缓存
css/style.css       全部样式（浅色 / 深色由 prefers-color-scheme 切换）
js/lib.js           公共工具：DOM、带种子的随机数、数学函数、画布绘图 PL.plot、控件、统计卡片
js/demos/*.js       每个文件注册同一类的若干个演示（PL.register）
js/map.js           关系图数据（EDGES / ROUTES / DOMAIN）、力导向布局、首页星图、侧栏小星图
js/app.js           分类定义（CATS）、路由（#/id）、侧栏、首页、每页底部的"它连着"
```

八个分类（按背后的结构）：个体理性集体变糟、样本是偏的、选择 + 噪声、维度与尺度、量法变了、反馈延迟与耦合、运气的形状、临界与涌现。

## 加一个新演示

1. 在对应分类的 `js/demos/*.js` 里调用 `PL.register({ id, cat, nav, title, hook, related, render(root) { … } })`。`render` 里用 `PL.panel`、`PL.plot`、`PL.stage`、`PL.prose` 搭页面；动画用 `PL.loop`，离开页面时会自动停止。
2. 在 `js/map.js` 的 `EDGES` 里给它加至少一条带原因的连线，并在 `DOMAIN` 里登记它的现实领域。
3. 新文件记得加进 `index.html`，并把所有 `?v=N` 加一。

## 说明

- 模拟里的参数多为示意，玩具模型（如佩托悖论、筛查悖论）在页面上已注明；引用的真实数据（Efron–Morris 棒球数据、Charig 肾结石数据、PEAR 实验等）在正文里给出了出处。
- 所有随机过程都用带种子的随机数，"重新抽样"按钮会换种子。
